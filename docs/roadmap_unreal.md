# Roadmap vers une version future

Cette feuille de route prépare une progression possible vers une version Unreal Engine, sans remplacer le prototype HTML actuel.

## Phase 1 — Prototype HTML existant

- Tester les idées.
- Vérifier les lieux.
- Tester les indices.
- Améliorer l'interface.
- Recueillir les retours.

## Phase 2 — Conception détaillée

- Écrire le contexte.
- Lister les lieux.
- Définir les rôles.
- Choisir le style graphique.
- Choisir les assets.
- Définir l'étage spécial.

## Phase 3 — Prototype 3D simplifié

- Créer une première map très simple.
- Tester les déplacements.
- Tester les collisions.
- Tester les lumières.
- Tester une énigme.

## Phase 4 — Version Unreal Engine

- Importer ou créer les assets.
- Créer la map.
- Ajouter les interactions.
- Ajouter les sons.
- Optimiser.
- Tester.

## Phase 5 — Version club de codage

- Répartir les rôles.
- Organiser les tests.
- Documenter le projet.
- Publier une version jouable.

# Rôles pour le club de codage

## Game designer

Imagine les règles du jeu, les objectifs, la progression et ce que le joueur doit comprendre à chaque étape.

## Level designer

Prépare la map, place les lieux importants, organise les chemins, les portes, les obstacles et les zones d'indices.

## Graphiste / modélisation

Crée ou adapte les visuels : textures, objets, icônes, éléments de décor et modèles 3D simples.

## Programmeur

Code les interactions, les menus, les déplacements, les énigmes, les sons et les corrections techniques.

## Testeur

Joue régulièrement au prototype, note les bugs, vérifie que les indices sont accessibles et signale ce qui n'est pas clair.

## Scénariste

Écrit le contexte, les textes d'indices, les dialogues éventuels et la logique narrative de la chasse au trésor.

## Responsable sons

Cherche ou crée les sons, vérifie leur volume, leur ambiance et leur cohérence avec les lieux du collège.

## Responsable documentation

Maintient les documents du projet, explique les choix et garde une trace des idées retenues ou abandonnées.

## Responsable licences

Vérifie les droits des images, sons, textures, musiques et modèles. Note les sources et empêche l'ajout de ressources non autorisées.
